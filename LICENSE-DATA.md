# Map data attribution

Map data © OpenStreetMap contributors.

OpenStreetMap data is available under the Open Database License (ODbL):
https://www.openstreetmap.org/copyright

Islo map styling and application code are separate from the underlying map data.

Official Korean cross-country bicycle-route coordinates are provided by the
Ministry of the Interior and Safety through the Korean Public Data Portal:
https://www.data.go.kr/data/3038533/fileData.do

The source dataset is free of charge and marked "no restrictions on scope of use".
